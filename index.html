What This Is

This site hosts 1 backend, 3 frontend demos, and a locally hosted AI Chat: React NextJS Demo, SolidJS Demo, Angular Demo, and Locally Hosted AI Chat. The frontend demos and AI Chat use the same .Net API backend. The Blazor mobile app is next. If anyone has any requests, please email me at recordstuff@hotmail.com.

The Self-Hosted AI Stack

The AI chat runs on a self-hosted language model on my Mac mini. Apple silicon's unified memory lets the CPU and GPU share the same memory pool, making the Mac a good fit for running local models.

Chat requests go through my C#/.NET API backend, which communicates with the Mac mini over my local network. The model is served by LM Studio's headless LMS server.

I'm still experimenting with different models and configurations, so there may occasionally be some downtime while I test or switch models.

How Is This Site Hosted?

Apache is the reverse proxy server, and the API is reused across the frontend subdomains. Apache routes each subdomain to the right Docker container based on that container's exposed port.

It is running on an older eight-core computer with 32 GB of RAM. Its fancy hardware aged out of Windows 11 support, but that ancient-but-powerful setup is perfect for Linux. The machine comfortably runs Apache and Docker Desktop for Linux.

Paired with LFT Fiber, my city's lightning-fast internet, it is the solution of my dreams: a super-fast site with more power and more room to grow than a free cloud tier, while I only pay about $20 a year to Squarespace and another $5 a month for a static IP.
