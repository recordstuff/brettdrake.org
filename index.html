Project details

What This Is

The React Inventory app is perhaps the most interesting thing here. It started as a demo, but I'm now turning it into a fully functional inventory app. The Angular and SolidJS demos are also hosted. All three frontends hit the same .NET API backend. I'm looking forward to building the Blazor demo as a mobile app with MAUI.

How Is This Site Hosted?

Apache is the reverse proxy server, and the API is reused across the frontend subdomains. Apache routes each subdomain to the right Docker container based on that container's exposed port.

It is running on an older eight-core computer with 32 GB of RAM. Its fancy hardware aged out of Windows 11 support, but that ancient-but-powerful setup is perfect for Linux. The machine comfortably runs Apache and Docker Desktop for Linux.

Paired with LFT Fiber, my city's lightning-fast internet, it is the solution of my dreams: a super-fast site with more power and more room to grow than a free cloud tier, while I only pay about $20 a year to Squarespace and another $5 a month for a static IP.
